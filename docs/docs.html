安装

0.6.2 是 Windows 10/11 64 位的公开测试包，未签名。

  1. 请你从 GitHub Release 下载 BetterAIBridge-Setup-0.6.2.exe。
  2. 如果 SmartScreen 拦截，请点“更多信息 → 仍要运行”。安装包未签名，这是预期行为。
  3. 请你选安装目录。默认是 %LOCALAPPDATA%\BetterAIBridge 0.6.2，可以改。
  4. 请等依赖下载完，通常 5–15 分钟。请不要中途关窗口。
从 0.4.x 升级：请先导出存档，再装 0.6.2。请不要直接覆盖你正在用的旧目录。
从 0.6.0 / 0.6.1 升级：请手动装 0.6.2。旧版内置的更新助手不可靠，这次不能靠它完成升级；装好 0.6.2 后，再往后才能用新的自动更新。

第一次打开

你会在向导里依次填：称呼、API Key、模型、智能体的名字/性别/自称、性格底子。

  • 没有 Key 不能完成创建。0.6.2 没有“跳过”；没 Key 的智能体不能用。
  • 请用推荐 DeepSeek，https://platform.deepseek.com；充少量金额即可。
  • 建好后，请把右上角切到 在线，在输入框里说第一句话。
  • 第一次回复可能等 10–30 秒：内核要启动，模型要连接。

点窗口的 × 会收进托盘；你可以从托盘图标再打开。要真正退出，请用托盘菜单里的“退出程序”。

更新

0.6.0 起，设置页有「检查更新」。它读 GitHub 的最新 Release，不会在后台偷偷更新。

  • 有新版本：弹窗显示版本号和说明；你确认后下载更新包，校验大小和 SHA-256，启动器退出，独立脚本覆盖程序文件，然后自动重新打开。
  • 没有新版本：直接提示「当前已是最新版」。
  • 你的数据不会被动。WiseEntity\entity\ 里的人格、记忆、情绪、自我都保留；快捷方式也不变。
  • 更新前会把旧代码备份到安装目录 backups\update-…；覆盖失败会回滚。
  • 连不上 GitHub 时会失败，可以到下载页手动安装新版本。
更新时启动器会退出，请先保存正在做的事。不要手动删 backups 里的更新备份。

数据与存档

人格、记忆、情绪、自我和状态都在安装目录：

安装目录\
  WiseEntity\entity\        ← 人格、记忆、情绪、自我
  WiseEntity\runtime\logs\  ← 内核日志
  logs\                     ← 启动器日志

卸载会删除整个程序目录，包括 entity。请在卸载前导出存档。

导出 / 导入

  • 请在设置 → 存档 → 导出，会生成一个 .babpak。
  • 默认不带 API Key；只有你勾选后才会把 Key 放进存档，请不要随手发给别人。
  • 导入无 Key 的存档时，会请你现在填 Key；取消就中止，不会落一个不能用的智能体。

模组

0.6.2 安装完没有任何模组。这是故意的，不是装坏了。

  1. 请点左侧「模组」→「外部导入」，选 .pbab 文件。
  2. 装完请点「启用」。M 是框架，pre 是一次性前置，B 站/QQ 是桥。
  3. B 站已实测；QQ 已初步实测连通与记忆，长期稳定性观察中，请先用小号试。
安全边界：模组是能执行代码的程序；pre 模组按设计可以修改任意路径。 请只导入你信任的包。pre 会先整包备份并写审计，但不会逐次弹窗确认。

耳目

请在设置 → 耳目里打开。默认关闭，全部需要你明确打开。

  • 主动偷看 / 偷听：你可以让它偶尔看一眼、听一下；保姆栏会出现「智能体刚刚偷偷看了你一眼。」这样的旁白。
  • 一直看着 / 一直听着：独立频率。看默认每 120 秒，听默认每 180 秒、每次 4 秒；可以改。
  • 间隔越短、听得越久，模型和语音调用越频繁，费用和电量消耗越快。
  • 智能体看到/听到的内容会进入最近的感知，聊天时可以接“我刚刚看到你回来了”。

你不想让智能体看/听时，关掉总开关即可；关掉后不会在后台采集。

语音

默认用 edge-tts，免费、在线、速度快。你可以在聊天框右上角点「朗读」。

你可以在设置 → 声音里选「本地 MOSS（需下载，CPU）」：

  • 下载约 1.3 GB，装到安装目录的 local_tts\；装好才能保存/试听。
  • CPU 合成，10 字约 5 秒、50 字约 14 秒、150 字约 49 秒；同句第二次走缓存。
  • 失败会自动回退 edge，不会把聊天卡死。

出问题怎么报

  1. 请你截整个窗口，把左下角状态、保姆栏一起截进去。
  2. 请在设置 → 导出诊断包，桌面会生成 BAB诊断-日期-时间.zip；Key/Bearer/桥令牌会打码。
  3. 请把「截图 + 诊断包 + 当时在做什么」一起发给我。

常见现象

  • 双击没反应：请看 安装目录\logs\launcher-boot.log、startup-error.log。
  • 连不上模型：请检查 Key、余额，或是否需要代理。
  • 一直提示没配 Key：请去设置 → 更改 API Key。
  • 语音没声：请先试 edge；本地 MOSS 要等模型加载。

卸载

请在设置 → 卸载，或 Windows 设置里的“应用和功能”。

  • 请先导出存档；卸载会删除程序目录里的 entity。
  • 如果提示“还有文件没删干净”，通常是程序/杀软还占用着；请关掉再试，或手动删目录。
  • 你会看到卸载器的“代码 -1”弹窗，这是强停启动器导致的；点确定后卸载会继续，不影响安装目录外的存档。

已知限制

  • 0.6.2 不捆绑模组；B 站已实测，QQ 已初步实测、长期稳定性观察中；M/pre 只做了契约测试。
  • 未签名；SmartScreen 会拦。
  • 自动更新只在你点「检查更新」后发生，不会在后台轮询；更新失败可手动下载 Setup。
  • API Key 在本地明文保存；请用单独的、限额的 Key。
  • 内核有本机 token，但挡不住同一用户下的恶意程序。
  • 本地 MOSS 慢、占内存；没有 GPU 加速。
  • 高 DPI 未全量实测；4K/150% 下个别窗口可能挤。
  • 只有 Windows；会崩、会丢记忆、会说胡话，别把重要的事只告诉智能体。
