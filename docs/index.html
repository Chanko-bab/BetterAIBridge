第一次打开

四步，把智能体接回家。

你拿到的安装包只有 1 个多 MB；依赖会联网准备，第一次通常 5–15 分钟。

下载安装包

请你下载 0.5.9 Windows 10 / 11 64 位安装包。未签名，SmartScreen 里请选“仍要运行”。

等依赖装完

需要联网。请不要中途关窗口；失败会把报错留在安装界面。

填 API Key

请填推荐 DeepSeek 的 Key。没有 Key 不能完成向导；这一版没有“跳过”。

切到在线

请在输入框里说第一句话。第一次回复可能慢 10–30 秒。

运行环境Windows 10 / 11，64 位
磁盘程序约 2 GB；本地语音包另需约 1.5 GB
